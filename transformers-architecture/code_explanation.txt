TRANSFORMER MODEL IMPLEMENTATION (STEP-BY-STEP EXPLANATION)

1. WHAT IS THIS MODEL TRYING TO DO?
This is a miniature auto-regressive language model (like a simplified version of GPT). 
Its sole job is to take a sequence of word IDs (numbers) and predict the NEXT word in the sentence.
It is Decoder-Only Transformer Model.
For example, when you feed it:
    "what" -> "is" -> "python" -> "<EOS>"
It learns to complete the sentence auto-regressively:
    "it" -> "is" -> "a" -> "programming" -> "language" -> "<EOS>"

2. STEP-BY-STEP CODE BREAKDOWN WITH AN EXAMPLE
Let's trace a simple sequence through each component of the code:
Prompt: ["what", "is", "python", "<EOS>"]

STEP A: Dictionary & Number Conversion (Tokenization)
Computers cannot process text directly; they require numbers.
- Dictionary (token_to_id):
  'what': 0, 'is': 1, 'python': 2, 'it': 3, 'a': 4, 'programming': 5, 'language': 6, '<EOS>': 7
- Input sequence ("what is python <EOS>"):
  Tensor: [[0, 1, 2, 7]]  (Shape: [1, 4] -> Batch Size = 1, Sequence Length = 4)

STEP B: Word Embedding (nn.Embedding)
- Raw integer IDs like 0 or 2 don't tell the model anything about meaning.
- The embedding layer converts each integer index into a list of numbers (a vector).
- Here, d_model = 2 (each token becomes 2 numbers):
    0 ("what")   -> [ 0.12, -0.85]
    1 ("is")     -> [-0.44,  0.91]
    2 ("python") -> [ 1.05,  0.33]
    7 ("<EOS>")   -> [-0.11, -0.62]
- Matrix Shape: [1, 4, 2]  (1 batch, 4 tokens, 2 numbers per token)

STEP C: Positional Encoding (PositionalEncoding)
- Self-attention processes all words at once and has no built-in sense of order.
- "what is python" and "python is what" would look identical without position information.
- Positional Encoding uses sine and cosine math formulas to assign a fixed position vector 
  to each spot in the sequence (Position 0, Position 1, Position 2, Position 3).
- Adding word embedding + position encoding gives each word both its MEANING and its POSITION:
    Combined = Word Embedding + Positional Encoding Vector

STEP D: Causal Self-Attention (CausalSelfAttention)
This is where the words "talk" to each other.
1. Query, Key, Value (Q, K, V):
   Each word creates 3 vectors using linear projection layers:
   - Query (Q): What is this word looking for?
   - Key (K): What information does this word carry?
   - Value (V): What actual content does this word share?
2. Attention Scores (Q * K^T):
   We multiply Query and Key matrices to calculate how much attention each word should pay to every other word.
3. Causal Masking (The Lower-Triangular Mask):
   When predicting the next word, the model CANNOT look into the future!
   For example, when processing "is" (token 2), it should only see "what" and "is", NOT "python" or "<EOS>".
   Mask Matrix (1 = Allowed, 0 = Blocked):
     [[1, 0, 0, 0],   <- Token 1 ("what") can only look at "what"
      [1, 1, 0, 0],   <- Token 2 ("is") can look at "what", "is"
      [1, 1, 1, 0],   <- Token 3 ("python") can look at "what", "is", "python"
      [1, 1, 1, 1]]   <- Token 4 ("<EOS>") can look at all 4 tokens
   Unallowed positions are masked with minus infinity (-inf), so after Softmax, their attention weight becomes 0%.
4. Output Calculation:
   Multiply attention percentages by Value (V) to get updated word representations.

STEP E: Residual Connection & Output Layer (fc_layer)
1. Residual Addition:
   Combine original position-encoded input with attention outputs:
     Updated Representation = Input + Attention Output
2. Linear Layer (fc_layer):
   Converts the 2-number vector back to the vocabulary size (8 tokens).
   For every position in the sequence, it outputs 8 raw scores (logits).
3. Softmax / Selection:
   The word with the highest score in the vocabulary is chosen as the predicted next word.

STEP F: Training Step (training_step)
- Input:  ["what", "is", "python", "<EOS>", "it", "is", "a", "programming", "language"]
- Target: ["is",   "python", "<EOS>",   "it",   "is", "a", "programming", "language", "<EOS>"]
- CrossEntropyLoss compares the model's logits against the target targets.
- The Adam optimizer calculates gradients and tweaks the 52 trainable parameters so scores 
  for the target tokens increase over training epochs.

STEP G: Inference / Text Generation Loop
How it generates text auto-regressively step-by-step:
1. Prompt: ["what", "is", "python", "<EOS>"]
2. Feed prompt to model -> Look at prediction for the LAST token ("<EOS>").
3. Prediction = "it"
4. Append "it" to prompt -> New prompt: ["what", "is", "python", "<EOS>", "it"]
5. Feed updated prompt to model -> Prediction = "is"
6. Append "is" -> Repeat until model predicts "<EOS>" or reaches max_length.

Final generated sequence:
  "what" -> "is" -> "python" -> "<EOS>" -> "it" -> "is" -> "a" -> "programming" -> "language" -> "<EOS>"
